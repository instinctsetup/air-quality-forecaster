# air-quality-forecaster

**Hourly air-pollution (CO) forecasting on the real UCI Air Quality dataset - a NumPy neural net trained with pinball loss, so it predicts *intervals*, not just numbers. Honest baselines included.**

The dashboard shows recent actual CO, a recursive 24-hour forecast, and an 80% prediction fan that widens as uncertainty compounds. Everything (network, loss, metrics, baselines) is from scratch - no sklearn, no torch.

## What makes this one worth reading

- **Quantile regression with pinball loss** - the network outputs p10 / p50 / p90, not a single guess. The interval *cannot cross* by construction (softplus deltas, see `forecaster/model.py`).
- **Honest evaluation against baselines** (`docs/eval-report.json`, regenerated by `train.py`):
  - 1 hour ahead: naive persistence wins (MAE 0.53 vs our 0.66). That is a *known phenomenon* for hourly pollutant series - the air at the next hour is mostly the air now. We say so in the UI instead of hiding it.
  - 24 hours ahead (recursive): the model beats flat persistence by ~26% (0.92 vs 1.25) and is within ~8% of seasonal-naive (0.85), while also producing calibrated intervals (74.6% coverage on an 80% target) that no baseline can give.
  - An exogenous-feature variant (adding NOx/NO2/T/RH) was tried and *hurt* test MAE (0.78 vs 0.66); the ablation is documented in `docs/MATH.md`. Features that don't generalize get cut, not kept.
- **Time-based train/test split only** - random splits leak the future in time series.

## Quick start

```bash
pip install -r requirements.txt
python train.py                 # trains, evaluates, writes forecaster/*.npz + docs/eval-report.json
uvicorn server:app --port 8000  # open http://localhost:8000
python -m pytest tests -q       # 9 tests
```

Trained artifacts are committed, so the server runs without retraining.

## Layout

```
forecaster/data.py       windowing (24 CO lags + cyclical hour encoding), time split
forecaster/model.py      NumPy MLP + pinball loss + softplus interval trick
forecaster/baselines.py  naive, seasonal naive, moving average
forecaster/metrics.py    MAE, RMSE, MAPE, interval coverage
forecaster/forecast.py   recursive multi-step rollout
train.py                 training + honest evaluation report
server.py                FastAPI: /api/forecast, /api/report
frontend/                fan-chart dashboard (vanilla JS canvas)
docs/                    MATH.md, VIVA.md, eval-report.json
```
